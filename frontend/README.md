# CRM Full Stack Application

A full-stack Customer Relationship Management (CRM) application built with React, Node.js, Express.js, and MongoDB.

## Features

- User Authentication
- Lead Management
- Contact Management
- Task Management
- Notes Management
- Sales Pipeline
- Dashboard & Analytics
- AI Sales Insights
- AI Lead Summary
- AI Email Generation
- Protected Routes
- Responsive UI

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- React Router
- Axios
- Recharts
- Lucide React

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

### AI
- Google Gemini API

## Project Structure

CRM/
├── backend/
└── frontend/

## AI Features

The application uses Google Gemini to provide:

- Sales pipeline health score
- Pipeline observations
- Sales recommendations
- Lead summaries
- Lead risk scores
- AI-generated sales emails
